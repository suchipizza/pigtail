The 30-second version

Pigtail's synthesis of the evidence below. Evidence level: Strong inference.

Agent-Reach is an MIT-licensed Python command-line tool that lets AI agents read and search sites such as Twitter/X, Reddit, YouTube, GitHub, Bilibili and XiaoHongShu without paid APIs. It chains free tools like yt-dlp, the gh CLI, feedparser, Jina Reader and Exa. Users install it by pasting a one-line prompt that points their agent to an install.md file. Created on February 24, 2026, it had 95,358 stars, 8,341 forks and 36 contributors by October 10, 2026, with most growth arriving in three short bursts that overlapped with GitHub Trending placements.

Growth mechanism

The clearest repeating pattern is GitHub Trending visibility. Agent-Reach first appeared in trending rankings on June 5, 2026, at #3 in Python. It reached #1 on June 15 and stayed on trending for 32 days. In early October it ranked #1 across all languages on October 2, and #3 overall and #1 in Python on Trendshift from October 2–4. Each of these stretches overlaps with a large star burst: about 20,000 stars from June 5–25 and about 7,700 from October 2–9. This fits a loop in which trending placement shows the repo to more developers and their stars keep it ranked. The sources record the overlap in timing, but none of them states that one caused the other.

Reusable tactics

Agent-executed install prompt

Instead of manual setup steps, users paste a one-line instruction containing an install.md URL into their AI agent, which performs the installation.

Mechanism: Removes setup friction for the target audience (agent users) by letting the agent do the work.

Date unknown: README instructs pasting a one-line instruction with the raw docs/install.md URL into an AI agent.

Needs: Users run AI agents that can execute shell commands
Documented

Ordered multi-backend fallback per channel

Model each platform as a channel with ordered backend choices so a broken upstream tool can be swapped without users changing their workflows.

Mechanism: Keeps the product working when upstream scrapers are blocked, preserving user trust.

What Agent-Reach did differently

Higher-level interpretation, separate from the factual record above.

Interpretation: rather than writing its own scrapers, the project presents itself as a capability layer that selects, installs, health-checks and routes to existing free tools. Each platform is a channel with an ordered list of backends. When Bilibili blocked yt-dlp, the tool switched to bili-cli without users rewriting their skills. Sources disagree on when this happened: most say June 2026, one says March. An 'agent-reach doctor' command reports which routes currently work. Installation is handed to the user's AI agent through an install.md prompt. The tool is also offered as an agent skill (npx skills add) and as a pip package, and it has READMEs in four languages plus a China mirror on AtomGit. The v1.4.2 and v1.5.0 releases in June removed unmaintained channels and added multi-backend routing.
